# 시넥스 AX 공개교육 (2026년 11월)

시넥스(Learning Bank)가 AX 전문 교육기관 헬로월드랩스와 협력해 진행하는 실무 교육 과정입니다.

- 주관: (주)시넥스
- 협력 AX 전문 교육기관: (주)헬로월드랩스 · 중소기업 인재 키움 프리미엄 훈련 과정 승인 기관
ChatGPT Work · Claude Cowork · n8n 중 원하는 AI 도구를 골라, 내 업무 자료로 직접 실습하며 업무 생산성을 높입니다.

- 교육비 90% 환급 (우선지원대상기업 고용보험 가입자)
- 부가세 10%는 사업자 요건 충족 시 별도 환급
- 과정별 AI 유료 계정 1개월 제공 (ChatGPT, Claude 등)
- 모든 과정 09:00 ~ 18:00 오프라인 진행, 개인 노트북 지참

## 과정 안내

### ChatGPT Work로 만드는 나만의 AI 업무 비서
자료 찾고, 옮기고, 고치는 일은 GPT에게 맡기고 나는 검토만. 회사 자료와 양식으로 내 업무용 GPT를 직접 만드는 실습 과정입니다.

- 기간: 2일 과정 (16시간)
- 일정: 잠실 · 가산 11.10 · 11.17 (화)
- 혜택: ChatGPT 유료 계정 1개월 제공

### Claude Cowork 기반 업무 자동화 실무
Gmail·캘린더·드라이브부터 회의 공지와 공급처 평가까지, Claude Cowork로 내 업무를 나눠 맡는 AI 팀과 반복 자동화를 직접 만드는 실무 교육입니다. 코딩 없이 진행합니다.

- 기간: 3일 과정 (24시간)
- 일정: 가산 11.11 · 11.18 · 11.25 (수) / 잠실 11.13 · 11.20 · 11.27 (금)
- 혜택: Claude 1개월 이용 제공

### n8n으로 코딩 없이 만드는 업무 자동화 AI 에이전트
단순 자동화를 넘어 '스스로 판단하고 실행하는' AI 에이전트의 구조를 이해하고, n8n으로 내 업무를 대신할 에이전트를 직접 만드는 실전 구축형 과정입니다.

- 기간: 3일 과정 (24시간)
- 일정: 잠실 11.12 · 11.19 · 11.26 (목) / 가산 11.13 · 11.20 · 11.27 (금)
- 혜택: Claude 유료 계정 1개월 제공

## 교육 장소

- 가산: 서울 금천구 디지털로10길 78, 가산테라타워 13층 (한국산업지능화협회 교육장)
- 잠실: 서울 송파구 올림픽로35길 123, 9층 (신천동 향군타워)

## 교육비 환급 절차

1. 교육 시작 전 교육비 전액 납부
2. 교육 참여
3. 교육 종료 후 헬로월드랩스에서 수료 처리 및 환급 신청
4. 고용노동부에서 사업주 환급 계좌로 환급

환급은 신청 후 보통 2~3주 정도 걸리며, 심사 기관의 처리 일정 등에 따라 더 늦어질 수 있습니다.

교육 신청은 각 과정 상세페이지에서 할 수 있습니다.
